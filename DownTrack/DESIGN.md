# DownTrack Visual Direction

DownTrack intentionally does not follow the original dark/minimal specification literally.

The new visual language is **Luxury Playful**:

- Windows 11 native foundation
- Mica backdrop
- vivid gradients
- bright cyan / violet / pink accents
- generous spacing
- large expressive typography
- premium glass-like surfaces
- restrained motion
- no permanent sidebar
- no dense dashboard chrome

The goal is to make a media-management utility feel like a polished consumer product rather than an administration tool.

## Visual rules

1. Color is used as personality, not as status noise.
2. Status colors remain reserved for meaningful states.
3. Gradients are concentrated in focal actions and hero elements.
4. Surfaces stay translucent so Mica remains visible.
5. Every screen must have one obvious primary action.
6. Settings and secondary commands remain quiet.
7. Empty states should feel designed, not unfinished.
8. Cards are large enough to breathe and small enough to scan.

## Interaction rules

- hover: subtle elevation/brightness
- press: short scale/opacity response
- page transitions: soft, never theatrical
- reduced-motion preference must be respected
- keyboard interaction remains first-class

## Brand palette

Primary: violet
Secondary: cyan
Warm accent: pink
Positive state: mint green

The palette is deliberately brighter than the earlier product specification.
